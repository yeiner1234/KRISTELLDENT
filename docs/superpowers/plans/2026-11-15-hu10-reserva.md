## Tarea 1 — Lógica pura de la Edge Function (TDD)

- `validateBookingPayload(payload, todayLima)` → `{ ok: true, value }` o `{ ok: false, error }`. Pruebas: falta cada campo obligatorio (incluido serviceId), DNI de 7 dígitos, nombre de 1 letra, correo sin @, teléfono de 8 dígitos, fecha pasada respecto de Lima, payload válido (recorta espacios, ignora endTime).
- `limaToday(now)` → fecha ISO en Lima. Prueba: `2026-11-16T02:00:00Z` → `2026-11-15`.
- `addMinutes('09:30', 45)` → `'10:15'`.
- `missingPatientFields(existing, incoming)` → solo los campos vacíos. Pruebas: no toca datos existentes; completa correo/teléfono nulos o vacíos; `{}` si no falta nada.
- `overlapErrorMessage(error)` → mensaje por restricción o null. Pruebas: los dos nombres (en `message` o `details`), otro código → null.
Commit: `test:` + `feat:`.
